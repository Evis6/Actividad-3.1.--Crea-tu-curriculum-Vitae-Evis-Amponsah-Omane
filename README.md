## 1. Descripción del Proyecto

Este proyecto consiste en una aplicación web de página única (*Single Page Application*) desarrollada con **ReactJS** y empaquetada con **Vite**, cuyo objetivo es presentar mi Currículum Vitae profesional de forma visual, limpia y estructurada.

La interfaz aplica arquitectura basada en componentes, renderizado dinámico mediante JSX y maquetación moderna con CSS3 para organizar mi perfil técnico, formación académica, certificaciones , habilidades y experiencia práctica en proyectos de desarrollo de software.
